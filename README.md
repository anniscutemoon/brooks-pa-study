## 规则要点（与教练约定）

- 按原书章节顺序学，不跳章；引用区分印刷页与PDF页，未核实标“待核实”。
- 每讲流程：定位 → 目标 → 复习 → 分段讲解 → 图/动画 → 随堂检查 → 费曼复述 → 习题 → 批改 → 存档。
- 动画与习题标注来源（原书图表解读 / 教学重绘 / 自编示意 / 真实历史数据）。
- 评级（难度/重要★1-5）为教学初评，随精读与作答表现修订。
- 课程成绩只反映课程内掌握度，不代表真实交易能力；不承诺盈利。
