# 术语表（中英对照 · 大白话）

每条记录：中文 / English / 大白话解释 / 首次出现位置。随学习持续补充。

## K线基础（L01 引入，零基础补课·对应《趋势》引言前置）

- K线 / candlestick — 把一段时间浓缩成的一根小柱子 — L01（补充）
- 开盘价 / open — 这段时间的第一笔成交价 — L01
- 收盘价 / close — 这段时间的最后一笔成交价 — L01
- 最高价 / high — 这段时间到过的最高价格 — L01
- 最低价 / low — 这段时间到过的最低价格 — L01
- 实体 / body — 开盘价到收盘价之间的粗块（站住的部分）— L01
- 影线 / wick (shadow) — 实体上下伸出的细线，到过没站住的部分 — L01
- 阳线 / bull candle — 收高于开（国内配色：红）— L01
- 阴线 / bear candle — 收低于开（国内配色：绿）— L01
